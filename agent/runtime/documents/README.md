# Markdown → PDF

直接从Markdown导出A4阅读版PDF，保留正文顺序、链接、公式、图注与书签。字体文件由调用者显式提供；工具不自动下载依赖或字体。

```bash
node export-pdf.cjs input.md output.pdf --font /path/to/body.ttf --heading-font /path/to/heading.ttf
```

中文长文推荐正文使用Noto Serif SC（思源宋体同源系列），标题、表格和图注使用Noto Sans SC。支持可变字重；不提供`--heading-font`时沿用正文字体。数学公式使用KaTeX专用字体，不用中文字体替代。

默认正文11pt、行距1.72，表格9.3pt、行距1.6；A4左右21mm留白。正文左对齐，避免中英文混排强制两端对齐造成空隙。标题与段间距有层级，表头跨页重复，图与图注尽量同页；不要靠连续空行调整分页。

导出后至少查看首页、表格较密的一页、含流程图及公式的页面。检查字号、字重、中文标点、英文与数字、行末换行、跨页表格、图片和图注；实际导出成功不代表视觉检查通过。超长表格行、不可拆分公式和高图片可能需要针对材料调整。

依赖见package.json。字体来源和许可证应随使用环境保存；Noto字体可从google/fonts的ofl/notoserifsc及ofl/notosanssc取得，许可证为SIL OFL。不将具体课题、机器路径或字体二进制写入通用默认配置。

成功导出的JSON包含源文、PDF、CSS、导出器及字体哈希，供现有项目导出记录复用。统一版式时核对本次交付范围内每个MD/PDF对应关系，补导仍使用旧样式的文件；长文与短文分别抽查。无需重导其他课题或已核验未变化的文件。
