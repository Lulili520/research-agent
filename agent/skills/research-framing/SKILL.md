# 研究问题建模

在检索前把 topic 转化为问题空间，避免看到文献后随意改变研究对象。使用[问题框架模板](assets/scope.md)生成 `scope.md`。

1. 明确研究对象、分析单位、干预或比较、主要结果、适用环境和研究类型。
2. 区分目标知识贡献与预期工程产物；明确什么观察会使问题失去价值或推翻核心前提。
3. 列出范围内、范围外和相邻但暂不处理的问题，并建立主要术语、同义词、旧术语和歧义词。
4. 记录数据、模型、算力、时间、伦理、许可证和外部权限约束。未知项写为待决问题，不能静默假设。
5. 阅读[问题质量检查](references/framing-quality.md)，运行 `researchctl.py audit-scope`；未通过时不能开始正式文献映射。

范围冻结用于控制选择偏差，不禁止合理修订。新证据迫使改题时，记录旧版本、变更理由及对已有检索的影响，再重新审计。
