# 顶级 CCF 会议完整研究标准

本标准汇总 ICML、ICLR、NeurIPS、ACL、EMNLP 等主会共同重视的科研要求，形成一套统一门禁，不预测或保证录用。不同研究类型可以用不同证据实现同一质量目标，但不得因拟投会议不同而降低科学标准。

## 1. 完整贡献结构

一项研究至少形成一条可审计的主论证链：

```text
重要且真实的问题
  -> 最近工作未解决的知识缺口
  -> 理论、机制、形式模型或系统不变量
  -> 区别于竞争解释的预测
  -> 决定性实验
  -> 强基线、消融与稳健性
  -> 有边界的结论与可复现 Artifact
```

“新模块 + 若干 benchmark 涨点”不是默认合格贡献。新颖性、技术正确性、经验可信度、重要性、可复现性和表达质量必须分别审计。

## 2. 统一质量维度

每项正式研究都按以下维度审计：

1. **重要性**：问题真实、具有广泛或关键影响，答案会改变理论认识、方法选择或系统设计。
2. **新颖性**：在有日期和范围的反向检索中未发现功能等价贡献，且差异具有科学后果。
3. **深度**：解释机制或原理，而不是只报告涨点、相关性或单个失败案例。
4. **理论性**：形式命题、完整假设、证明与可检验推论；经验/系统模式必须明确不声称数学证明，并提供同等级机制或不变量论证。
5. **正确性**：推导、实现、数据、统计与结论均可审计，主张不超过证据支持范围。
6. **实验充分性**：决定性实验、强基线、公平预算、消融、竞争解释、失败分析与不确定性完整。
7. **泛化与稳健性**：检查最重要的模型、任务、数据、表达或环境变化，明确适用边界。
8. **可复现性**：数据版本、代码、配置、随机性、计算资源、原始产物和表图重建路径齐全。
9. **伦理与数据治理**：许可、隐私、风险、人工参与、模型使用与局限透明。
10. **表达与可验证性**：问题、贡献、假设、方法和结论清晰，读者能定位每项声明的证据。

这十项是合并后的共同标准，不是十个可相互补偿的分数。任何致命缺陷都能阻止推进；不适用项必须基于研究类型说明理由，不能因目标会议不同而删除。

## 3. Proposal 充分性门禁

Proposal 是实验前的科学论证合同。以下门禁审查计划是否能够产生可区分、可反证的新知识，不要求未来实验已经得到正结果。实际结果只影响后续证据审计和论文结论，不能反向伪造或否决当时合理的 Proposal。

Proposal Builder 必须回答：

1. 一句话核心主张是什么，什么结果会推翻它？
2. 最近的功能等价工作为何没有已经回答该知识问题？
3. 理论或机制如何产生至少一个竞争解释无法同时预测的结果？
4. 最小决定性实验是什么，为什么它比扩大 benchmark 更有信息量？
5. 若核心假设为负，仍产生什么可发表知识？
6. 计划中的完整论文除核心实验外还需要自然发生证据、方法、外部效度或 Artifact 中的哪一层？
7. 预算内是否能取得足以支持主张的证据，而不是只能完成低功效演示？
8. 统一质量十维中是否存在尚未覆盖的致命层？

输出 `Paper sufficiency`：

- `insufficient`：主张增量、不可识别、资源不可行或只有演示。
- `promising`：核心问题成立，但完整论证包仍缺关键层。
- `proposal-ready`：最近邻、机制、决定性实验、失败价值和完整论文路径均明确。

同时分别输出 `Proposal decision`、`Novelty status`、`Empirical status` 和 `Execution readiness`。其中 `Empirical status: not-run` 是 Proposal 的正常初始状态；只有设计在原则上不可操作、不可识别或根本不可执行且无替代路径时，才影响 Proposal 决策。

## 4. 实验充分性

实验组合按“它排除了什么解释”选择：

- 主实验直接检验核心主张；
- 强基线排除已有简单方法足以解释收益；
- 消融删除被声称必要的组成；
- 机制实验区分主机制与竞争解释；
- 稳健性检查预先最重要的分布、模型或环境变化；
- 效率实验报告实现该收益所付出的资源；
- 失败案例界定适用域。

不得要求所有论文无限增加模型和数据集。新增实验若不改变任何主张、威胁或边界，应停止扩张。

## 5. 论文就绪门禁

进入投稿就绪前必须满足：

- 标题、摘要、引言、方法/理论、实验、局限和结论中的主张与 evidence ledger 一致；
- 所有核心表图可从冻结原始产物重建；
- 最强基线、数据划分、随机性、统计不确定性和计算预算透明；
- 负结果、协议偏离和失败 run 未被隐藏；
- Artifact 在干净环境通过最小复现；
- 至少一轮不继承作者结论的模拟审稿已处理重要性、新颖性、深度、理论、正确性、实验、稳健性、复现、伦理和表达的致命问题；
- 选择具体投稿会议后，再根据当届官方规则联网核验格式、匿名、页数、伦理、数据/模型许可和披露要求；这属于提交合规，不改变统一科研门禁。

模拟审稿可以判定 `not-ready`、`major-revision` 或 `agent-review-cleared`；最后一项只表示自动化内部证据门禁通过，不表示客观投稿就绪或会被接收。
