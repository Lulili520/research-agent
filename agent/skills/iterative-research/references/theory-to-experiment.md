# 理论—实验契约

理论支撑可以是形式推导、因果图、机制模型、资源/复杂度模型、信息论分析、统计模型或由既有理论导出的可检验解释。仅复述直觉、引用术语或为方法添加公式不构成理论依据。

`theory.md` 至少记录：

1. 构念与可观测量：抽象概念如何映射为实际变量和指标。
2. 假设与适用域：数据、模型、环境、资源和独立性条件。
3. 机制链：自变量为何以及通过什么中间过程影响结果。
4. 竞争解释：至少一个能解释同一现象的替代机制。
5. 区分性预测：主解释与竞争解释分别预测什么趋势、交互或边界。
6. 反证条件：哪些可观察结果会削弱或推翻核心解释。
7. 实验映射：每个预测对应的操纵、控制、测量和分析。

为支持自动审计，以上内容分别保留 `Constructs:`、`Assumptions:`、`Mechanism:`、`Competing explanations:`、`Predictions:`、`Falsifiers:` 和 `Experiment mapping:` 英文元数据标签，标签后的正文仍使用中文。

若无法直接观察机制变量，应说明代理变量的构念效度及可能误差。理论只能限定可预期现象，不能替代实验结果；实验相关性也不能自动证明所提机制。

创新方向只有同时满足以下条件才能进入确认性实验：与最近强工作的不可约差异明确；差异具有科学后果；理论产生可区分预测；存在可执行且能失败的实验；负结果仍能缩小知识空间。
