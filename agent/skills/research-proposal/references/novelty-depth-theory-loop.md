# 新颖性—深度—理论闭环

本流程用于顶会理论型 Proposal。目标不是生成听起来新颖的标题，而是找到能经受等价工作检索、形式反例和决定性实验的知识主张。

## 1. 问题图谱而非关键词列表

从 topic 建立五层图谱：现象、任务/环境、机制、方法、评测。每层记录同义词、旧术语、相邻领域表述和可迁移理论。先找领域已经解释了什么，再找哪些解释互相矛盾、哪些重要现象尚无可识别解释。

## 2. 候选生成

至少提出三个知识贡献不同的候选。候选应来自以下一种或多种张力：

- 理论预测与经验结果冲突；
- 两组高质量工作结论冲突；
- 现有方法有效但机制未知；
- 重要边界条件或失败模式无法由现有理论解释；
- 现有理论依赖现实系统不满足的假设；
- 评价指标与真正目标构念错位。

不得只通过替换模型、数据集、损失项或拼接模块制造候选。

## 3. 新颖性攻击

把候选拆为问题、形式命题、机制、算法/系统、实验识别和证据贡献，逐项执行：

1. 精确术语与同义词检索；
2. 功能等价描述检索；
3. 相邻领域旧术语检索；
4. 最近理论工作的定理/假设检索；
5. 前后向引文与作者后续工作；
6. benchmark、代码与未正式发表版本；
7. 寻找明确的负结果、不可行性和反例。

每个原子声明标记 `known|incremental|unresolved|candidate-novel`。只有 `candidate-novel` 且差异具有科学后果，才能保留。最后连续两轮定向攻击没有改变核心声明，才达到范围稳定；仍不得宣称绝对无人做过。

## 4. 深度攻击

对候选回答：

- 它解释了什么此前无法解释的现象？
- 若成立，会改变哪条理论认识或系统设计原则？
- 最简单竞争解释是什么？
- 哪个结果只符合本机制而不符合竞争解释？
- 负结果是否仍能排除一类重要解释？
- 是否能导出一个跨任务或跨模型的可迁移结论？

只说明“指标可能提高”的候选判为浅层；只能靠更多 benchmark 增加篇幅的候选判为不充分。

## 5. 形式理论预审

在 Proposal 阶段定义：对象、随机变量/状态、量词、适用域、假设、结论和证明义务。至少给出一个证明草图并完成：

- 假设去除测试：移除每个假设，尝试构造反例；
- 极端/退化情形；
- 维度与单位一致性；
- 小规模有限枚举或符号检查；
- 与最近定理逐项比较；
- 非平凡性检查：结论不能由定义直接推出；
- 相关性检查：定理必须约束算法、机制或实验预测。

失败时修订或淘汰候选；不得先宣称理论贡献，再把证明困难留给论文阶段。

## 6. 决定性实验预审

为定理/机制的经验推论设计最小实验，明确主机制、竞争解释和零效应分别预测什么。理论证明逻辑命题；实验验证假设在现实系统中的适用性、效应大小和边界，二者不能互相替代。

## 7. 选择与收敛

候选按六项独立评分并写出证据：科学重要性、范围内新颖性、理论非平凡性、可证伪性、资源可行性、完整论文潜力。评分只用于候选排序，不用于通过门禁；任何 `proposal-fatal` 都可以否决高总分候选。

Proposal 只有同时满足以下条件才为 `proposal-ready`：

- 新颖性范围稳定且反方审计通过；
- 研究问题树、贡献层级、确认性核心、必要边界、最小外部效度与扩张停止规则通过独立深度—广度审计；
- 当前 Proposal 完成五轮全流程复核，旧版本轮次未被复用；
- 核心形式命题有可信证明路径，无已知反例；
- 机制产生区别性预测；
- 最小决定性实验可执行；
- 正、负、混合结果均有明确知识含义；
- 计划中的完整论文论证包在预算内可完成。

本门禁不要求决定性实验已经运行。实际操纵是否成功、效应量、显著性、跨模型稳健性和 Artifact 复现状态写为 `Empirical status: not-run` 下的依赖，交给后续阶段判断。
