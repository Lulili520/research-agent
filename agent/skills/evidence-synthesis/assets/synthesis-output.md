# <研究问题>：文献调研总结

## 直接回答与阅读边界

先回答用户的问题，再说明证据支持的范围、检索截止、必要分支及尚未解决的关键问题。实际纳入数、摘要定位数、重点章节分析数和深入精读数分别记录，口径互不冒充；数字由已有记录核验，不填目标数量。用户未要求时不追加来源覆盖表。

## 领域问题与方法脉络

解释核心概念、必要子问题及其联系。按“原问题 → 既有方法的不足 → 后续改变 → 仍存边界”组织发展脉络；说明跨方法比较所需条件，不只列论文标题或年份。

## 共识、分歧与证据强弱

围绕重要判断解释最强支持、反向证据、适用条件和不确定性，给出就近来源及关键定位。区分定义不同、设置不同和仍无法解释的冲突；不可比的数值说明原因。精确指标、公式与缩写先定义后使用。

## 核心论文解读

分类下先给共同问题与路线区别，再为每篇核心论文提供独立可理解的说明。不能在一段里并列数个方法名就视为逐篇解读。以下是内容顺序，不要求每篇机械复用相同标题；理论和实证来源按类型调整。详略随其对中心问题的重要性调整，篇幅不能代替理解。

### <官方标题>

实际版本、发表身份、已读范围及核心定位。

**背景与研究动机**：必要名词就地解释，用具体困难说明原有方法哪里不足；缩写全称不是概念解释。

**方法介绍**：先用例子走通输入—处理—输出，再解释关键组件、必要公式和训练/推理区别。理论或实证论文采用对应的重建方式。

**结论**：说明实验/证明设置、基线、指标、主要发现、决定性消融或反例；准确定位并保留不确定性，不能用“显著有效”代替证据。

**启发**：先写作者已经带来的知识或能力，再写有依据的限制；对当前课题的启示另段说明，不能改写论文原意。

## 未解问题与下一步

每个保留问题说明：缺少什么证据、为什么现有方法尚不足以回答、与直接近邻的具体差异、什么观察或检验能改变判断。标记哪些是领域证据限制、哪些只是本次未读或未取得材料。按影响领域结论的程度排序，不默认生成正式 Proposal。

## 参考文献

默认使用普通可点击引用和编号文献，适配用户阅读器；不让脚注原始标记阻断阅读。稳定身份与官方链接；同一工作的多个版本合并计数，实际阅读版本另行标明。

结论与启发的写作口径：结论先概括实验或证明支持什么认识、有哪些条件和反向证据，数字只作必要支撑；详细数值与对照记录可保存在内部论文卡。启发针对整篇论文，解释它如何改变问题理解、方法设计或证据判断，哪些思路可借鉴及适用边界；不能只重复结果或集中列局限，也不强行落到当前候选。用户要求四段结构时明确呈现背景与动机、方法、结论与启发。
