# 预测—实验映射

每个核心声明使用 `C<n>`，假设使用 `H<n>`，预测使用 `P<n>`。`theory/claims.jsonl` 保存假设与声明，`theory/predictions.jsonl` 保存可检验预测。

每条预测必须说明：关联假设和声明、可观察量、主机制预期模式、至少一个竞争解释的预期模式、适用范围、会削弱主机制的结果，以及实验所需的操纵、控制和测量。`expected_pattern` 与 `rival_pattern` 不能相同或只是“更好/更差”的空泛描述。

预测只规定判别信息，不预注册具体实现细节；数据划分、基线、指标、随机性和统计方法在后续实验协议中冻结。一个实验可以检验多个预测，但每个核心预测至少要有一个现实可行的实验映射。
