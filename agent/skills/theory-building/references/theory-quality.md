# 理论质量与竞争解释

理论可以是形式模型，也可以是明确的机制模型，但必须回答：什么变量在什么条件下，通过什么中间过程影响什么结果。构念必须对应可观察量或说明代理测量误差；假设必须限定适用域，不能隐藏在结论中。

竞争解释不是主机制的措辞变体。优先考虑更简单的混淆解释、资源规模效应、测量偏差、优化效应、数据泄漏、选择效应或已有机制。主机制与竞争解释必须至少在一个可观察趋势、交互项、中介变量或边界条件上给出不同预测。

以下情况不能通过：结果好坏都被理论解释；预测只复述方法目标；机制变量没有测量方案；只引用理论名词而无推导链；关键假设与数据或系统设置矛盾；最近工作已经提出实质相同解释但未比较。
