分支由原问题产生；一条证据可支持多个问题，不累加成独立篇数。执行结果与计划分开；只找到标题不能关闭需要全文回答的问题。正式项目的执行身份和输入版本可交给 taskqueue 登记，本表只保存科学问题与证据判断。

长期问题状态使用 open、answered、blocked、out-of-scope；范围内已有答案仍可因新证据或发现误读而重新打开。跨轮修正保留问题ID、日期、旧/新判断、来源、影响的claim及报告位置，记录在现有证据账本中，不另造一套机器阶段。
