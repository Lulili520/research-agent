# 论文解读的理解依赖与修复

用于用户指出“介绍粗略、名词看不懂、背景不足、方法跳步、看完不知收获”，或综述中的核心论文不能独立阅读时。目标是修复读者理解所必需的内容，不以扩写字数、增加标题或词汇表代替精读。

## 先定位读者断在何处

从用户的知识背景出发；没有额外说明时，不假设读者了解本课题专用缩写、论文自定义构念或隐含基线。通用基础只解释到理解当前机制所需的程度，不自动扩成教科书。

对受影响的每篇核心论文依次检查：

1. **问题入口**：读者能否说出一个具体失败情境，原方法在哪一步不足，论文要改变什么？只写“现有方法效果不好”不够。
2. **概念依赖**：关键名词是否用直观含义和任务角色解释，而非只展开英文全称？后一个概念是否依赖尚未解释的前一个概念？
3. **方法链**：能否从一个具体输入追踪中间数据、组件调用、目标/输出，再到训练或实际使用？明确谁产生信息、什么时候可以看到、哪些部分被更新。
4. **验证关系**：是否知道对照在排除什么解释、指标测量什么、原结果支持哪一步？不只呈现涨点和一句“有效”。
5. **知识收获**：先说明论文自身贡献，再说明对用户问题的启发、适用条件及尚不可推出的结论。不能只给局限或把论文当作候选方案的赞成/反对票。

这些是语义检查问题，不是要求每篇必须有五个固定标题。理论论文使用命题、假设、证明路线和边界例；诊断/实证论文使用变量、干预、对照与识别链；无需训练时不强加训练过程。

## 区分表达缺口与证据缺口

- **已有依据，解释缺失**：重写必要背景、就地定义、样本链及证据到结论的连接；说明属于解释修复，不宣称新增发现。
- **自己不能走通**：写下具体卡点并返回原文相应方法、公式、图注、附录或官方代码。禁止用合理猜测补完作者流程。
- **材料未取得或来源未说明**：分别标注，不把它们写成同一种作者缺陷。不能通过润色把这篇提升为完整精读。
- **新的核查改变旧理解**：先修正当前论文卡及原子证据，再修正文中依赖该理解的比较和选题；保留旧解释与日期。

## 先把一篇讲通，再压缩成同类比较

一个分类可以包含多篇，但每篇承担中心证据时，要有读者能够独立理解的解释单元。分类概览只能介绍共同问题与差异，不能替代逐篇方法说明。相邻论文名称连续出现、读者却无法对应其输入和输出时，拆开重写。

推荐论证顺序是：具体问题及必要背景 → 一个完整方法/识别例子 → 必要公式及组件 → 关键证据 → 作者贡献与边界 → 对当前问题的启发。避免在读者尚不了解作者做法时，先集中讨论公式瑕疵、统计不足或新颖性碰撞。

已有长解释只需修复缺口，不重复介绍全部基础。术语表可以辅助查阅，但第一次使用重要概念仍须给出局部解释；不能要求读者不断跳到另一篇或文末才能理解当前段落。

## 例子必须真正解释机制

说明性构造要显式标记，不能伪装为原论文案例或运行结果。例子必须对应作者实际的信息流、目标与执行条件；不能把信息获取方法演示为真值直接输入，也不能把事后标签变成决策时可见答案。

至少解释一个关键组件为何需要：去掉它后，同一个例子的哪一步会改变或失败？这是一条可检查的机制解释，不等于声称论文已做过该反事实实验。实际消融的结果另行引用。

公式先解释所表达的关系，再说明符号和计算单位。训练输出、损失位置、数据来源、参数更新与推理使用分别讲清。共享基础只讲一次；同名量定义不同则就地比较，不能静默沿用。

## 修复后的验收与记录

用文本实际提供的信息回答：原问题是什么？基线为什么不足？输入如何走到输出？组件分别起什么作用？证据支持什么？还有什么不能判断？缺任何必要答案，继续对应的重写或取证；不根据标题齐全、字符数、术语出现次数或脚本通过宣布完成。

在原论文卡或已有检索记录中按需保存“缺口—原文定位—修复后的解释/例子—剩余限制”。不为普通润色启动正式科研状态机，不强制新增独立审计人或额外任务文件。表达修复、原文补读、新证据发现和科学结论改变分别记录。

用户报告使用目标阅读器支持的基础Markdown。首次出现的论文用可读名称及普通来源链接；不支持脚注时改普通链接，避免遗留未渲染标记。中文标签优先写作`**解释**：正文`，将标点置于加粗之外。渲染检查验证显示效果，不验证科学理解。

## 将背景与例子融入叙述

用户报告默认使用简洁的“背景与动机—方法—结论—启发”组织；标签写作`**结论**：…`，不反复添加实验/理论等括号说明，证据类型在正文中交代。内容齐全优先于标签齐全，避免每篇都堆相同的小标题。

例子先交代任务背景、已有信息与具体困难，再展示方法怎样改变处理过程。用“例如”“设想”自然引出并融入方法，不称“教学样本”“教学样本链”，避免与真实训练样本混淆。报告开头可以统一说明构造例子的身份；原文案例仍需就地标明出处与证据，数值推导说明为本文计算。构造例子不得虚构作者实验、引入部署时不可见的答案，或取代必要背景和方法细节。

全篇检查重复背景、同义段落和无作用的标签。每章围绕一个共同问题组织，先解释必要背景和路线差异，再逐篇展开，最后综合共同认识、条件与冲突；不能只把论文卡顺次拼接。
