# 论文精读

目标是让读者能说明方法怎样工作、为什么这样设计、结论由什么证据支持。访问全文、解释清楚和证据充分分别判断；流畅复述不证明理解，复杂措辞不证明深度。

## 先确定阅读问题

确认官方题名、稳定标识、实际版本、发表身份和可访问材料。先通览全文结构，再提出必须回到原文回答的问题：作者解决什么困难，方法的关键变化是什么，哪个结果支持中心主张，什么替代解释仍可能成立。问题来自论文及当前知识缺口，不能从摘要结论反向填写“已解决”。

已有卡片先核对已读范围、未解问题及来源版本，只补缺失或受影响的部分。按当前问题优先补读方法、决定性对照和相关附录；依赖前序工作才能理解时，追溯定义或算法来源后再回来。不能只检索几个片段宣布读完。

## 走通方法与证据

1. **还原问题与先例**：交代研究对象、输入输出、假设和原有方法的具体不足。区分作者宣称的新增贡献与本次已核验的差异，不能只复述“首次”。
2. **重建方法**：选一个能暴露关键机制的具体输入，走通处理、输出及适用的训练/推理过程。说明每个关键组件解决什么困难、与基线在哪一步不同。理论论文改为命题—假设—证明依赖及边界例；实证研究改为变量、处理、对照和识别路径，不强加算法或 GPU 模板。
3. **解释必要公式**：先解释直觉，再定义符号、条件和计算顺序。适用时核对维度、采样、损失分母、梯度路径或极限。例子与自己的推导明确标记，并回到原文校正；保留误解及修正，不要求公开隐式思维过程。
4. **追到决定性证据**：逐项连接核心主张、实验/命题、对照及允许结论。检查主要结果、关键消融、失败案例和相关附录；核对数据/split、基线、预算、随机性与不确定性。理论工作检查证明义务、关键步骤、反例和假设是否包含结论。
5. **按歧义核对实现**：论文表述不足且实现会影响判断时，只读核查官方代码、配置或数据规范，记录版本、已查路径与差异。代码存在不等于复现成功，阅读不授权执行实验。

承载中心结论的图实际查看图像和图注；表格核对表头、脚注、单位与聚合方式。解析乱码时查看原页面，不能据提取错误批评论文。原文未报告、材料未取得和自己尚未读懂分别记录，不能混成“作者缺少”。

每项质疑都要指出来源位置、尚未排除的替代解释及受影响结论。作者报告、可复核推导、本次推断分别标明；不批量追加“更多模型/数据/种子”作通用局限。

## 把分析写清楚

沿“背景与动机—方法—结论—启发”组织连贯解读，使用[论文卡片](assets/paper-note.md)。顺序是：直观问题与例子 → 方法步骤 → 必要公式 → 关键证据 → 结论边界。方法介绍中先完成一条端到端说明，再展开变体与技术细节。

- 首次出现的缩写、指标和核心术语给出含义；同一符号保持同义。只解释理解中心主张所需的背景，避免堆术语。
- 一个段落围绕一个问题展开。方法说明、结果报告与有效性质疑分段；数字紧跟对应设置和比较对象，不能让读者自行猜测分母或指标。
- 原文贡献与证据边界讲完后，再单列对当前课题的启示。单篇独立阅读不强加课题或 Proposal；不能把论文缩成预设方案的支持/反对票。
- 区分两种未清楚：写法使读者看不懂时重写解释；自己尚未理解时返回原文，不能靠润色掩盖。

## 读者理解困难时的修复

用户指出术语、背景、方法或收获不清时，执行[解释修复](references/explanation-repair.md)。先定位问题入口、概念依赖、方法链、验证关系和知识收获的具体缺口；已有依据但没讲清就重写，自己走不通就返回原文。不能只补缩写全称、堆公式或在末尾追加局限。

综述中的核心论文也须能独立读懂：分类概览不替代逐篇解释，不能用相邻论文的背景隐式补全本篇。先说作者解决什么及怎样解决，再谈消融、质疑和对课题的启发。顺序按论文类型调整，内容要求不等于固定标题或字数配额。

## 结论与启发不能被方法摘要替代

每篇承担中心证据的论文都交代四项内容：动机说明具体问题与旧方法不足；方法走通输入到输出及关键设计；结论说明主要证据与关键对照支持的认识，并交代设置和边界；启发说明可迁移的思路、替代解释、失败条件及对当前问题的启示。用户要求显式结构时使用相应标题或段落标签，默认用“结论”概括证据支持的认识，不堆“结果（实验结论）”等括注。理论论文以命题、证明结果和反例替代实验分数。

结果至少解释一个决定性比较为什么有用，并检查其是否与主实验使用同一划分、训练阶段、预算及聚合方式。主要结果、消融、诊断和外部复用结果分开；论文自己的评价材料不能静默变成课题的固定测试清单。数字存在不代表有显著性或机制证据；原文未报告的不补造。

四项中的证据缺失须回原文补读，不能通过添加四个空标题或通用局限宣布修复。每篇独立验收，不能用几篇代表作的深入解读抵消其余核心论文的缺口。

## 验收与交接

交接前逐项检查能否从解读中回答：问题为什么重要；一个输入如何变成输出；相对基线的关键变化；核心结果具体支持什么；哪些条件下不能外推。关键方法必须有可复核例子、伪代码、推导或等价的识别/证明重建。选择适合论文类型的检查项，详见[研究设计评价](references/design-appraisal.md)。

阅读深度按实际证据记录：

- **元数据/摘要**：身份与研究对象定位，不承担方法效果判断。
- **局部正文/重点章节**：能解释已读部分，明确缺失章节、图表或理解依赖，不计为完成深入精读。
- **深入精读**：关键方法/证明、主要证据、关键消融及相关附录已检查，关键问题已回答或准确界定为来源限制。关键内容未取得或未读懂时保持待补读。

阅读记录保存“问题 → 原文定位 → 自己的解释/推导 → 答案状态 → 剩余缺口及影响”。答案状态为已回答、来源未报告、来源冲突、材料不可访问或尚未读懂。批次更新替换当前摘要、保留有日期的修正记录，不能留下互相冲突的完成标签。

项目卡片存入 `.research/review/papers/`，单篇请求直接交付解读。多篇材料交给 `evidence-synthesis` 形成领域判断；模板填满、篇幅增加或结构检查通过均不能替代语义验收，也不构成独立审计。

结论与启发的写作口径：结论先概括实验或证明支持什么认识、有哪些条件和反向证据，数字只作必要支撑；详细数值与对照记录可保存在内部论文卡。启发针对整篇论文，解释它如何改变问题理解、方法设计或证据判断，哪些思路可借鉴及适用边界；不能只重复结果或集中列局限，也不强行落到当前候选。用户要求四段结构时明确呈现背景与动机、方法、结论与启发。

## 将原文关键图纳入解读

用户需要图文解读或关键图明显有助于理解时，默认优先选择论文主要方法、架构或训练—执行流程图，帮助读者追踪输入、组件、监督与输出。实验截图不作为默认配图；仅用户需要或论证确有必要时采用结果图。无论是否转载，承担结论的实验图表仍须实际阅读和核对。不强制每篇配图，不把图的存在当作深入精读。裁切只去除无关版面，保留理解所选图所必需的图例、箭头及文字；复合图可只截方法面板，须明确标注所选面板及省略内容，不写成保留完整原图；截取后再次目视核对边界，不用生成图重画论文证据。

图片放在课题输出的相对资源路径中，内部来源记录保存PDF哈希、物理页码、原图号、裁切坐标及图片哈希。正文就地标注论文来源、实际版本、页码与原图号，并解释应先看哪里、信息流或对照是什么、支持什么结论和哪些外推不成立。作者图中的主张和本次解读分开。原图裁切不替代方法解释，也不自动构成新的实验或完整精读。

决定性证据不能被概括词抹去：结论至少说明改变了哪个因素、相对哪个对照、在何种条件下成立。需要时保留同设置数值锚点，检查首次执行与重试后表现、预给信息与自主获取信息、参数更新与推理计算是否混淆。公式只保留解释机制所需内容，但关键归一化、权重、分母及梯度路径不能省略到无法复核。
