# Agent 回归评测

修改 Agent 后至少检查：Skill 路由是否准确；检索是否保留完整查询和排除理由；摘要证据是否被限制在摘要级结论；CCF 标签是否核验届次、track 和 paper type；数值比较是否具有兼容设置；研究空白是否完成最近工作与反向检索；所有报告是否默认使用简体中文。

每日精读不设发表时间下限，优先从 ICML、ICLR、NeurIPS 官方 Oral、Spotlight、获奖论文和其他高价值未读候选中，按全文证据质量与科研启发性选择最多三篇；已精读论文不得重复，无合格论文时不得凑数，摘要筛选不得冒充全文精读。

## 模块路由场景

- “近期有哪些高质量论文值得读”：进入每日三篇近期论文精读，不自动启动完整课题调研。
- “调研量化模型的 Agent 评测”：进入目标课题调研，不以昨日热度限制文献集合。
- “从今天热点里挑出与量化 Agent 相关的方向并深入调研”：先运行雷达，用户或明确规则选定候选后再交接到目标课题调研。
- 新增能力模块必须具有独立触发条件和输出契约，不能改变上述两个模块的语义。
