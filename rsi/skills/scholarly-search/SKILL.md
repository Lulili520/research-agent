# 学术检索

输入是研究问题、当前问题树、用户来源/时间约束与已有证据。输出是真实可访问的来源、逐篇相关性判断、缺口和下一项取证动作，不是搜索引擎结果列表。

## 从问题到候选

先列影响答案的必要分支与关键术语，考虑同义表达、旧称和相邻领域。以问题术语进入领域官方来源、代表作和引用链，再用候选贡献反向查最相近工作。用户指定来源优先覆盖；其他来源按问题相关性判断，不继承别的课题会场清单。

读实际摘要再判断：论文解决什么、分析单位是什么、方法或结果怎样影响当前问题。分别标注直接工作、相邻机制、理论/数据/效率背景或排除；记录理由和摘要来源。高影响背景也要理解，但影响力不等于证据强。

同一工作合并版本，记录阅读的是哪一版；发表身份与内容访问深度分别核验。优先官方全文、proceedings、作者授权版本、数据和实现。不编造标题、数量、DOI 或页码。

## 定向补检

每次检索记录查询、来源、日期、实际检查候选、选择理由、尚未回答的问题。已知直接近邻用作召回检查：未能找到时修正术语和来源，不用“搜不到”支持新颖性。

优先补会改变结论或方案排序的证据，包括强基线、反例、负结果与假设不成立的设置。并不强制每个主张都找到反例；没找到就记录检索范围和不确定性。

停止由问题覆盖和剩余缺口影响决定；预算耗尽另记。篇数、引用数和固定搜索轮次不能证明覆盖充分。

## 交接

将实际材料保存为 source 快照，声明 origin、阅读版本和 access（abstract/full-text/data/code）。网页摘要不能标 full-text。每个精读任务明确要核验的主张/公式/比较，附完整引用与可访问路径。全文不可得时安排替代来源或降低可支持的主张，不伪造深入理解。

检索记录是材料，真正的综合结论交给 evidence-synthesis；精读交给 paper-analysis。
