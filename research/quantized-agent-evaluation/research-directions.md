# 量化模型 Agent 性能评测：收敛后的研究方向

检索截止：2026-08-26  
结论性质：问题导向的初步新颖性审计，不是穷尽性系统综述，也不构成“全球无人做过”的保证。

## 结论先行

建议把论文主线收敛为：

> **构建一种有效性校准的配对轨迹评测方法，识别量化干预导致 Agent 首次语义行为分歧的位置、类型及其向最终任务失败的传播机制。**

这比“再做一个量化 Agent benchmark”更有科研价值：ACBench 已经证明压缩会损伤真实 Agent 任务，但总分不能解释损伤从何发生；现有轨迹评测与 benchmark 有效性研究提供了方法组件，却没有在本次记录范围内发现把“同一基础模型的量化/全精度配对干预、轨迹分歧归因、结果验证器审计”合为一个研究设计的直接等价工作。

成本与重复运行不应分别包装成独立创新，而应成为主方法的必要评价层。安全不是当前主线；只有在后续专项新颖性审计确认量化对高风险约束存在独特效应时，才升级为独立方向。

## 主方向：有效性校准的量化 Agent 配对轨迹归因

### 精确研究空白

已有工作能够比较量化前后的任务分数、工具能力和生成成本，但仍不能可靠回答：在相同模型、任务初态与受控随机条件下，量化首先改变了哪个**语义决策**，该变化属于工具选择、参数构造、计划更新、状态记忆、停止判断还是错误恢复，以及这个局部变化是否真的造成最终环境状态不同。

这是“机制 + 测量有效性”缺口，而不是简单覆盖缺口。若结果验证器本身会误判结构化输出或部分完成，则观察到的量化退化可能是 benchmark 伪差异；若只对齐 token，又会把语义相同但表述不同的轨迹误判为分歧。

### 最近工作与不可约差异

- ACBench（ICML 2025）直接研究压缩模型的 Agent 能力，已经覆盖工具、工作流、长上下文和真实任务；它确立“静态能力保持不代表闭环能力保持”，但没有形成配对语义轨迹的首次分歧归因。
- QLLM-Eval（ICML 2024）提供较完整的量化变量与一般能力评测，但不是环境交互研究。
- T-Eval、AgentBoard 与近期轨迹评测工作提供分阶段能力或过程诊断，但没有把量化作为受控干预。
- Agentic Benchmark Checklist 揭示 task validity 与 outcome validity 会显著改变 Agent 能力估计，但没有研究这种误差是否对全精度/量化条件产生差异性偏置。
- Quantization Inflates Reasoning 研究 token 膨胀与重复推理，包括 agentic tool use，但不等价于环境状态对齐的动作错误传播分析。

**不可约差异**：不是增加模型或指标，而是让研究者能从“量化后掉了多少分”推进到“量化在何种状态下改变哪类决策、该改变是否被恢复、为何最终失败，以及 benchmark 是否正确记录了失败”。

### 可证伪假设

- H1：在控制基础模型、任务、scaffold、解码与初态后，量化会使首次语义轨迹分歧集中于少数行为类型，而非均匀发生。
- H2：首次分歧的位置与类型，比静态量化指标或总 token 数更能预测最终任务失败。
- H3：部分表面量化退化由结果验证器的差异性误判造成；校准验证器后，效应量或方法排序会显著变化。
- H4：量化造成的局部分歧并非必然失败，Agent 的恢复能力是连接局部误差与最终结果的中介变量。

### 实验骨架

1. 选择 2–3 个可本地复现、具有确定性环境状态检查的 agentic benchmark，并先按 task validity / outcome validity 审计任务与验证器。
2. 固定同一基础模型、prompt/scaffold、工具版本与硬件；比较 BF16、至少两个 PTQ 位宽/方法，量化位置作为因子而非论文标题。
3. 对每个任务和条件做多种子重复运行；保存模型输出、解析动作、工具结果、环境状态、错误与恢复事件。
4. 以“语义状态—动作等价类”对齐轨迹，定位首次分歧；抽样使用双人标注校准自动分类器，报告一致性与混淆矩阵。
5. 主要结果报告配对效应、置信区间、分歧时间、失败传播/恢复概率，以及验证器修复前后的效应变化。
6. 把总 token、prefill/decode 时间、显存、工具调用和重试折算为“每个成功 episode 成本”，作为部署解释层而非另立贡献。

### 正结果与空结果的贡献

- 若存在稳定敏感行为：得到量化 Agent 的机制性失败分类和后续选择性精度保护目标。
- 若分歧不集中：否定“修复单一组件即可恢复 Agent”的简单假设，并说明需要面向随机闭环的系统级评测。
- 若验证器偏差显著：纠正已有 benchmark 推断，并贡献可复用的有效性审计协议。
- 若量化差异落在 rollout 方差内：得到特定模型/位宽/任务范围内的可部署否定证据，而非无结果。

### 风险与控制

- token 级轨迹不可直接配对：以环境状态和语义动作等价类为基本单位。
- 自动轨迹 judge 可能有偏：优先确定性状态检查，并用盲法人工复核校准。
- 因子过多导致算力爆炸：先做 2 个模型 × 3 个精度条件 × 2 个 benchmark 的功效导向核心设计，再扩展外部有效性。
- benchmark 污染或任务无效：记录数据来源，优先动态/可验证任务，公开排除规则。

### 新颖性状态

**暂定：中高置信候选，而非已证实首创。** 截至 2026-08-26，在已记录的直接组合查询中未发现等价研究。会推翻该判断的工作是：已经系统地对同一 LLM 的全精度与量化 Agent 做多次配对 rollout，以语义/环境状态定位首次分歧，归因错误传播，并校准结果验证器。正式立项前仍需完成多数据库结果计数、ACBench 等最近工作的前向/后向引文链和代码/作者检索。

## 备选一：量化条件下的 Agent 可靠性响应面

研究量化方法/位宽与随机 rollout、提示扰动、工具超时、schema drift、长任务 horizon 的交互，重点是方差、尾部失败与恢复，而非平均成功率。

- 最近工作：τ-bench、ReliabilityBench 等已经做通用 Agent 重复运行和扰动可靠性，因此“多跑几次”没有新颖性。
- 保留的差异：把量化设为受控干预，估计其与外部扰动的交互效应及 worst-group/CVaR 风险。
- 适用条件：如果预实验发现量化效应主要表现为方差或尾部风险，而首次分歧类型不稳定，可将它升级为主线。
- 新颖性置信：中等；需继续排查 2026 年量化鲁棒性预印本。

## 备选二：面向成功任务成本的量化 Agent 精度配置

研究权重、KV cache、prefill 与 decode 精度怎样影响完整成功 episode 的能力—成本 Pareto，并用主方向的失败归因解释为何某些“单 token 更快”的配置反而每次成功任务更贵。

- 最近工作：Token Inflation 已揭示推理 token 隐性成本，Mix-Quant 已区分 prefill/decode 风险；单独报告成功任务成本不够形成强新意。
- 保留的差异：将阶段精度配置、闭环失败/重试机制与成功 episode 的端到端成本置于同一受控因果设计。
- 适用条件：如果目标会议更偏系统，且可获得可靠的延迟、显存和能耗测量，可作为系统向论文；否则作为主方向的评价层。
- 新颖性置信：中等偏低到中等，取决于是否导出新的自适应精度策略，而非只画 Pareto 曲线。

## 暂不作为独立主线

- **量化 Agent 安全性**：重要但范围过大，且 Agent-SafetyBench、AgentAuditor、MIRAGE、AgentIF 已覆盖相邻构念。当前只适合作为高后果子集验证，除非专项检索证明存在量化特有、稳定且可解释的安全退化。
- **统一比较更多量化位置**：与 QLLM-Eval、Mix-Quant 重叠较大；只有当它解释轨迹机制或产生新精度策略时才有论文级价值。
- **新建综合总分 benchmark**：容易成为任意加权，且不能解决构念和结果有效性；优先贡献透明的多轴协议与原始指标。

## 立项门槛

在投入大规模实验前，必须同时满足：

1. 完成 Semantic Scholar、Google Scholar、DBLP、arXiv、OpenReview 和目标 CCF 会议近两年 proceedings 的可复现检索记录；
2. 完成 ACBench、Quantization Inflates Reasoning、Mix-Quant 及最近轨迹评测的前向/后向引文链；
3. 制作至少 10 篇最近工作的 overlap/delta 表，并让一名独立研究者尝试推翻新颖性；
4. 在小规模预实验中证明轨迹能可靠记录、语义动作能校准、主要效应有可估计精度；
5. 将主张写成日期和范围受限的形式，并在投稿前刷新检索。
